# Phase 2 — footage-transform-lab 迁移测试报告(2026-07-07)

## 测试设定
Phase 1 的 living-painting 位移配方建立在**单帧静照**上。本阶段把它迁移到 IMG_3695.mov **视频本体**,检验哪些步骤可复用、哪些是素材特异性假设。

## 迁移结果:三个隐藏假设被暴露

1. **静态遮罩假设**:配方的矩形遮罩假设锁定机位。实测素材是推进镜头(cam_motion_check.png:首尾帧差显示画从中景推到满幅特写),静态遮罩直接失效。
2. **静止底板假设**:先在满幅特写段(11–15s)直接套用——呼吸位移(静帧时运动量 ≈2.5)被相机运动(13–55)完全淹没,机制在动镜头上**不可见**。"活化"的效果身份要求(近)静止底板。
3. **恒定曝光假设**:iPhone 自动曝光逐帧泵动全画面亮度,稳像后差异图上墙/地面出现亮度带——静照永远不会暴露这一点。

## 修正管线(v2,全部实测)
选全片最稳窗口(逐秒运动量扫描,0–3s 最稳)→ 相位相关逐帧跟踪全局平移(降采样 1/4 灰度 FFT,累计漂移 x −48px)→ **稳像与呼吸位移合并为单次重采样**(coords = 稳像偏移 + key-field 位移,避免两次插值损失)→ 墙面区域逐帧增益归一锁曝光 → 画框/墙真正静止、画布呼吸。

## 复用成功 / 素材特异性清单
| 步骤 | 迁移 |
|---|---|
| key-field 位移引擎(粗网格+smoothstep 换场) | ✅ 原样复用 |
| 软遮罩 + feather | ✅ 原样复用(坐标不变,因为已稳像回 f0 参考系) |
| 帧差图验收法 | ✅ 原样复用,且额外暴露了曝光泵动 |
| 静态矩形遮罩 | ❌ 只适用锁定机位;动镜头需跟踪(平移已实现;推进的尺度变化未实现,是已知缺口) |
| 底板静止 | ❌ 新前置条件:先稳像或选稳定段,机制才可见 |
| 曝光恒定 | ❌ 手机实拍需曝光锁(墙面基准增益归一) |

## 量化
src(0–3s)运动 7.81 → 输出 8.67(稳像抵消漂移后仍高于源,增量即呼吸);帧差图:画布亮、画框仅 1–2px 残余抖动、墙面曝光带被增益锁基本消除。

## 残余缺口(如实)
- 平移跟踪不够推进镜头用:尺度+旋转的相似变换跟踪未实现(需要时再做,或交给 AE 真跟踪)。
- 稳像用 nearest 边缘填充,漂移大时画面边缘有 48px 拖影带(本段在画面外侧,不显)。
- 滚动快门/透视残差无法用全局平移消除。
