# Phase 7 — 物理现象 sonification 映射(2026-07-07)

## 现象素材
4.physical-phenomena-sonification.mov = Instagram Reels 屏录(blackwatercozumel 黑水潜水):半透明深海幼鱼,翼状大鳍,黑水中脉冲推进。**生命过程 = 鳍的开合推进循环**。前 18 帧是 reel 滑动过渡,已剔除(数据污染实测:面积饱和→崩零)。

## 结构变量提取(4 个,numpy,亮度阈值分割 >26/255,黑水背景天然抠像)

| 变量 | 提取法 | 实测特征 |
|---|---|---|
| 鳍展面积 area | 分割 mask 像素数,p5–p98 归一 | 4s 起从 0.1 涨到 0.7(鱼游近),叠加鳍拍振荡 |
| 质心速度 velocity | 帧间质心位移,5 帧平滑 | 节律性峰,与推进冲程对应 |
| 边界复杂度 complexity | 周长/(2√(πA))(圆=1) | 1.5–7.5 振荡,鳍开=复杂,收=简单 |
| 脉冲周期 period | 面积自相关峰 | **0.27s/拍**(8帧@30fps) |

## 声音映射(概念:鳍的开合就是这只生物的呼吸,让它可听)

| 结构变量 | 声音参数 | 理由 |
|---|---|---|
| 面积 | 谐波堆 detune 展宽 + 整体振幅^0.7 | 鳍展开=身体变成更宽的膜=频谱变宽 |
| 复杂度 | 谐波数量(1–8 阶逐个点亮) | 轮廓越皱,音色越富 |
| 脉冲周期 | 低频振幅调制(sub pulse,锁 0.27s) | 推进节律=声音的呼吸律 |
| 速度 | 噪声颗粒事件(阈值 0.5 以上概率触发,12ms 衰减) | 冲刺=水被搅动的颗粒声 |

**不做**:不配和弦、不加节拍器、不铺氛围垫——所有声音成分都能指回一条数据曲线(非科普配乐)。漂浮段(变量低)声音自然稀疏=静默保留。
