### 6. 完整清理重建 Material SOP 管线
由于第一次失败导致部分节点残留，执行清理+重建：
```python
# 清理旧的 matsop
for nm in ["matsop_top","matsop_mid","matsop_bot"]:
    if g.op(nm): g.op(nm).destroy()

# 断开 merge1 所有输入
merge1 = g.op("merge1")
for c in list(merge1.inputConnectors):
    c.disconnect()

# 创建 3 个 Material SOP，连接并设材质
for idx, name in [(0,"top"),(1,"mid"),(2,"bot")]:
    rot = g.op("rot_"+name)
    mat = g.op("mat_"+name)
    msop = g.create(materialSOP, "matsop_"+name)
    msop.inputConnectors[0].connect(rot)
    msop.par.mat = mat.path
    merge1.inputConnectors[idx].connect(msop)

# 清除 Geo COMP 的全局材质
op("/project1/rubik").par.material = ""
```
→ `{"ok": true, "result": "done: matsop_top(yellow)/matsop_mid(cyan)/matsop_bot(pink) -> merge1"}`
