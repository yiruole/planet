# 案例:雪夜闪光状态切换(压力测试,2026-07-07)

来源:用户提供的 10.6s 1440×1440 竖屏视频(小红书风格)。完整闭环:逆向 → Blender 双状态底板 + numpy 时序合成 → 三轮对比迭代。工作目录 `~/Desktop/Digital Art/blender/snow_flash_test/`(build_base.py / composite.py / snow_flash_v3.mp4 / compare_*.png)。

## 机制结论(OBSERVED 支撑)

**"同一静态底板的状态切换合成"**:暗蓝夜态(2.2s)→ light-leak 胶片灼烧闪光(彩虹渐变压下,~0.4s 全白)→ 亮态 + 三层景深降雪 + grain。关键证据:前后状态场景逐像素一致;闪光是全画面滤色(树无新增投影);闪光与音频 +18dB drop 在 ±1 帧内同步(astats RMS 包络测得)。

## 复刻路线(验证有效)

1. Blender 无头渲同一场景两个灯光状态(A:暗蓝月光 sun 0.55;B:正面 area 900W 泛光,雪面大增亮)——真重打光优于分级模拟
2. numpy/ffmpeg 合成:时序切换 + 屏幕混合彩虹 wash(洋红左/琥珀右,`f**2.2` 提白)+ 程序化三层雪(远:300 小点微痕;中:110 拉长雪痕 streak 9px;近:18 个 22px 高斯模糊 bokeh)+ grain σ2.6
3. 三轮迭代的修正:闪光从单一暖色→三色带才"像胶片";雪层不透明度 0.55→0.80 才可见;夜空数值要亮 3–5 倍(AgX 压黑)

## 失败记录

| 失败 | 原因 | 修法 |
|---|---|---|
| 渲染夜空全黑 | AgX view transform 把低值(<0.01)压死 | 夜空色值按直觉 ×3–5;或合成端亮度遮罩补蓝(luma<46 & 画面上部 → 加 navy),比重渲便宜 |
| 地形面片感 | displace 后默认平直着色 | 逐 polygon `use_smooth=True`(无头模式下不能用 bpy.ops.shade_smooth 的 context) |
| 闪光浑浊 | 多色渐变用加权平均混合导致去饱和 | 分区域纯色带(clip 权重)+ screen 混合 |
| 抽帧循环全部空产出 | zsh 不做 `$var` 单词拆分,`set -- $spec` 失效 | 显式逐条命令,或 `${=spec}` |
| A 态蓝调分级无效于天空 | 乘法分级作用在近 0 值上仍是 0 | 先加(lift)后乘,或渲染端解决 |

## 未达成(诚实清单)

底板资产保真度:树的真实感(参考是照片级挂雪云杉,复刻是程序化雪簇锥体)、桦树枝、雪面微起伏纹理。这些是资产工作量问题,不是机制问题;机制三要素(状态切换节奏/闪光形态/雪层次)均可辨识对应。
