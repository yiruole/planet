# Fidelity Rules — 视觉保真迭代方法

复刻/参考驱动的任务在"机制验证通过"之后适用。核心:**机制正确 ≠ 视觉接近**。

## 双关卡验收

1. **机制关**:核心视觉机制可辨识地对应参考(结构、时序、因果)。达标时只允许宣布"机制验证通过",不允许宣布"复刻完成"。
2. **保真关**:逐维度对照,直到"最大的 3 个视觉差距"不再属于可修复范围,或用户确认停止。宣布任何完成度之前必须跑过一轮证据面板(见工具)。

## 每轮迭代的强制动作

1. 生成证据面板:`python3 ~/.claude/skills/creative-rules/scripts/compare_fidelity.py <ref> <ours>`(图片或视频;需 matplotlib,用 anaconda python)
2. 读面板 + 读图,写出**当前最大的 3 个视觉差距**,每个必须标注:
   - 来源分类:A mechanism / B asset / C geometry / D material / E lighting / F camera / G render / H compositing / I temporal
   - 感知影响(占画面面积 × 注视优先级,粗略排序即可)
   - **盲区配额**:若存在未关闭的"面板不可见差距"(见下方盲区声明),3 席中至少保留 1 席给它。可测量差距会天然垄断排序——排序被"可测量性"绑架时,循环只优化面板测得到的东西(backrooms 案例:时序差距吃满五轮预算,资产语义差距从未上桌,"brown boxes" 一路进成片)
3. 只修感知影响最大的差距;每轮改动 ≤3 个变量(iteration-rules)
4. **修正路由约束**(防止被"便宜的修正"俘获):
   - 差距来源是 asset/geometry → 禁止调 shader、加 post 来掩盖;要么改资产,要么明确登记为妥协
   - 差距来源是构图/camera → 禁止用 post-processing 补;回到机位/布局
   - 差距来源是 motion/temporal → 禁止用颜色/材质转移注意力
   - 差距来源是 lighting/render(如曝光分布、AgX 压黑)→ 优先渲染端;合成端补救要登记
5. **豁免台账**:MVP 阶段的每项妥协(如"树是简化资产")必须显式登记;机制关通过后**强制重审**台账,逐项决定:修复 / 继续豁免(写理由)/ 用户裁决。禁止静默永久豁免。
6. **proxy 升级票据**:draft-first 允许代理资产起步,但每个 proxy 建立时必须同时开票:升级成什么、什么条件触发。**机制关通过 ≠ proxy 转正**——票据只能被保真关逐张关闭或由用户显式豁免。没有票据的 proxy 会在机制关通过后静默转正(backrooms 案例实证)。票据的关闭方式有两种:**参数/资产修复**或**路线切换**——同一张票连续 2 轮修不掉,自动升级为路线决策,禁止第 3 轮继续调参硬撑。
7. **路线重审(反路径依赖)**:每轮开工前先答一个问题:"本轮头号差距,用当前管线 1 轮内能否明显改善?" 答不上或答否 → 先做候选路线比较(fidelity ceiling / 成本 / 风险 / 是否保留已验证机制 / 是否引入目标漂移)再动手。已有脚本不是继续用它的理由(backrooms 案例:程序化家具再调 2 轮也出不来二级形态,但成像链一轮就换了量级)。
8. **视觉交付关(强制)**:任何复刻任务的收尾必须交付 参考/旧版/新版 逐格对齐的并排对比图(+视频效果附可播放成片),让用户能肉眼裁决。只报数字、只报"机制正确"、只报规则改了什么,都不算完成。

## 检查维度(看的清单,非算的清单)

**工具化的 4 项**(人眼最易骗,面板机械呈现):亮度分布(直方图+暗/亮部占比)、边缘/细节密度(全局+分块比值)、尺度分布(元素大小对比)、事件时序(视频:亮度曲线+事件时刻)。

**面板盲区声明(必读)**:证据面板只输出全局统计——以下维度它**结构性测不到**,原语堆和真家具堆在面板上几乎不可区分。这些维度必须走人工目检 checklist,每轮在差距清单里逐项给出"通过 / 差距 / 豁免"三选一,不许跳过:

1. **asset semantics**——画面元素能否被命名为具体物件;"说不出这是什么"= 红旗
2. **topology diversity**——凹形/孔洞/薄壳/框架占比;全凸包 = 红旗
3. **object scale distribution**——尺度是否跨数量级、是否重尾;窄带均匀随机 = 红旗
4. **contact plausibility**——接触/支撑/重力姿态;穿插与悬浮 = 红旗
5. **occlusion depth**——遮挡层数与内腔阴影;浅层大块重叠 = 红旗
6. **material spectrum**——粗糙度/反射/磨损的方差;单一漫反射 = 红旗

盲区维度**不建自动指标**(反 Goodhart,也别掉进 ML 视觉工具链黑洞)——checklist 本身就是它们的 gate。

**镜头形成链(shot formation chain)——"语义内容 ≠ 同一个镜头"**:物件清单、布局、灯光状态全对,画面仍可能一眼假。复刻的目标是参考的**成像结果**,不是场景清单。以下四组必须作为独立差距来源检查(backrooms 案例:资产升级三轮后,单轮成像链修正的感知增益超过全部资产轮):
7. **camera/lens**:机位高度/俯仰/距离/焦距压缩感/DOF/焦点面/畸变/主体占幅
8. **lighting structure**:曝光平台高度、key/fill 比、墙面回光、腔体深黑、高光在形体上的落点结构(不只是"灯开没开")
9. **atmosphere**:雾/尘/体积污染/纵深分离
10. **imaging pipeline**:传感器噪声结构(亮度+色度)、压缩纹理、锐度/涂抹、黑位抬升、高光滚降、halation、色偏——低清参考的"脏"是身份的一部分,干净渲染 = 立刻穿帮

**读图判断的项**:构图/轮廓(silhouette 复杂度)、空间布局、前中后景密度、色彩分布、材质响应(高光/SSS/透射)、边缘特征(硬/软/halo)、景深线索、透视/焦距感、资产保真、渲染特征(噪点/AA)、合成痕迹。

**视频追加**:事件时刻与时长、运动幅度与方向、加减速特征、重复结构、声画同步(astats RMS 包络法,见 reference-reverse-engineer §3.5)。

## 反 Goodhart 纪律

- 不打总分、不用 SSIM/LPIPS 类相似度指标——分数会变成优化目标,面板只提供证据,结论由带上下文的判断做
- 面板数值(如亮部占比)用于**发现差距**,不用于"刷到一致"——分布形状对了但画面不像,以画面为准
- 工具维度按需增补:某次复刻暴露了面板盲区才加,不预建分析器
