# Evidence Rules — 视觉分析证据分级

所有创作系统 Skill 在做参考分析、效果逆向、教程学习时必须遵守。

## 三级证据分类

每个分析结论必须归入且仅归入一级:

- **OBSERVED** — 直接从素材看到/测到的事实。帧内容、ffprobe 元数据、明确可见的 UI 操作、可读的节点名。必须能指出出处(帧号/时间码/文件)。
- **INFERRED** — 由 OBSERVED 推出的技术判断。必须写明推理依据 + 置信度(high/medium/low)。例:"高光滚动方式表明是 3D 渲染而非 2D 合成 (high)"。
- **UNKNOWN** — 无法从素材判断的部分。明确列出,不许省略。不知道就是不知道。

## 红线

- 只读了字幕 ≠ 看了视频。声称"分析了视频"之前,至少要有:ffprobe 元数据 + 代表帧抽取 + 逐帧观察记录。
- 只抽了几帧 ≠ 理解完整时间结构。要描述时间演变,必须有覆盖全程的采样(contact sheet 或分段抽帧)。
- 没分析过的内容不许声称理解。宁可写 UNKNOWN。

## 置信度写法

- **high**:多个独立视觉证据指向同一结论,或有排他性特征
- **medium**:单一证据支持,存在其他解释但可能性较低
- **low**:仅凭经验猜测。low 置信度的推测必须提供验证方法

## 输出结构(所有逆向分析通用)

1. OBSERVED 清单(带出处)
2. INFERRED 清单(带依据和置信度)
3. UNKNOWN 清单
4. 2–3 条候选 pipeline + 各自 trade-offs
5. 推荐路线 + 理由
6. 最小复现实验(MVP)定义
7. machine-readable JSON(结构见 reference-reverse-engineer skill)
